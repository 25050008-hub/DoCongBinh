Giới Thiệu Bản Thân

Tôi là Đỗ Công Bình, sinh viên ngành Lập trình Web / Công nghệ Thông tin. Tôi yêu thích việc biến các ý tưởng thiết kế thành sản phẩm web thực tế có khả năng tương tác cao và chuẩn tối ưu UI/UX.

Mục Tiêu Nghề Nghiệp

Mục tiêu ngắn hạn

Làm chủ kỹ năng Front-End Web (HTML/CSS/JS ES6+), thực hành chuyên sâu các React/Vue framework và hoàn thành tốt dự án thực tập.

Mục tiêu dài hạn

Trở thành Full-Stack Developer chuyên nghiệp và đảm nhận vai trò quản lý kỹ thuật (Tech Lead) trong các dự án công nghệ lớn.

Kỹ Năng Chuyên Môn

HTML5 & CSS3

Semantic HTML, Responsive Flexbox/Grid, CSS Animation & Variables.

JavaScript (ES6+)

DOM Manipulation, Async/Await, ES Modules, Fetch API & Event Handling.

Python / Java

Tư duy OOP hướng đối tượng, xử lý thuật toán và cấu trúc dữ liệu cơ bản.

Git & GitHub

Quản lý mã nguồn, Git Branch, Merge conflict & làm việc nhóm GitHub.
